Cambios principales:
- Nuevo lenguaje visual SublimArts.
- Galería intermedia, entre la versión anterior y la galería grande.
- Las imágenes de producto usan object-fit: contain para evitar deformaciones/cortes.
- Cada producto muestra medida y precio.
- "Ver más" individual abre el mismo visualizador/modal.
- "Ver más" de sección muestra inicialmente hasta 10 productos.
- Hero usa una etiqueta <img> editable desde HTML.
- CSS organizado y preparado para reutilizar esta estructura como plantilla de otras categorías.

Rutas de imágenes:
Las rutas originales del HTML se conservaron. Para reemplazar una imagen, edita directamente el atributo src del <img>.
